# CodeOrbit To-Do List Web App

A simple, clean, and responsive To-Do List application that helps users manage daily tasks. Tasks are saved in the browser using localStorage, so they remain available after refreshing the page.

## Technologies Used

- HTML5 — webpage structure
- CSS3 — styling and responsive design
- JavaScript — task management and DOM manipulation
- localStorage — persistent browser storage
- Git and GitHub — version control and project hosting

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Display total and completed task counts
- Save tasks after browser refresh
- Responsive user interface

## Setup Instructions

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd CodeOrbit_Todo-List-App
   ```

3. Open `index.html` in your web browser.

4. Start adding, editing, completing, and deleting tasks.

**Requirements:** A modern web browser. No Node.js, database, or additional dependencies are required.
